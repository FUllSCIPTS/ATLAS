# Phone listing screenshots

The Android acceptance workflow captures actual app screens on a 9:16 phone emulator.
Google Play allows up to eight phone screenshots; the documentation shows all twelve.
Recommended listing selection: 01, 02, 03, 04, 06, 07, 08 and 09.

| File | Suggested alt text |
|---|---|
| 01-home.png | ATLAS Go home with Ride, Share ride and Food options |
| 02-ride-booking.png | Saved pickup and destination places with a demo fare estimate |
| 03-ride-confirmed.png | Simulated ride confirmation, driver details and journey controls |
| 04-shared-rides.png | Shared ride offers with seat availability and per-seat prices |
| 05-shared-confirmed.png | Shared journey confirmation for a two-seat party |
| 06-food-home.png | Three illustrative restaurants available for demo food ordering |
| 07-food-menu.png | Restaurant menu with item descriptions, prices and basket buttons |
| 08-basket.png | Basket items, delivery fee, total and demo checkout |
| 09-order-tracking.png | Simulated food order status and delivery-stage control |
| 10-activity.png | Local history of rides, shared journeys and food orders |
| 11-profile.png | Guest profile, privacy information and reset controls |
| 12-privacy.png | In-app explanation of local data and deletion options |

The verifier rejects blank images and Android captures outside Play's size/aspect limits.
